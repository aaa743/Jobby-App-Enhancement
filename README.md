Jobby App - Job Search Portal
A comprehensive job search application built using React JS.

Key Features:
Authentication: Secure login using JWT tokens and Cookies.

Job Search: Filter jobs by employment type, salary range, and location.

Responsive Design: Fully optimized for both mobile and desktop views.

Detailed Views: Specific job details with company info and similar jobs.

Tech Stack:
Frontend: React JS, React Router, React Icons.

State Management: Component State.

API Handling: Fetch API with async/await.
